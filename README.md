## 📖 درباره پروژه

**6SwagDirT** یک فروشگاه آنلاین لباس است که با **React** در فرانت‌اند و **Node.js + Express + MongoDB** در بک‌اند ساخته شده. این پروژه یک سیستم کامل فروشگاهی شامل **پنل مدیریت**، **سبد خرید**، **علاقه‌مندی‌ها**، **سیستم احراز هویت** و **درگاه‌های مدیریتی** می‌باشد.

### 🎯 اهداف پروژه

- 🎨 طراحی مدرن و حرفه‌ای
- ⚡ عملکرد سریع و بهینه
- 🔒 امنیت بالا با JWT
- 📱 کاملاً واکنش‌گرا (Responsive)
- 🛒 تجربه خرید روان

## ✨ امکانات

### 🛒 بخش کاربری

| ویژگی | توضیح |
|-------|-------|
| 🏠 **صفحه اصلی** | نمایش محصولات ویژه، دسته‌بندی‌ها و بنر |
| 🛍️ **فروشگاه** | مشاهده همه محصولات با فیلتر و مرتب‌سازی |
| 🗂️ **دسته‌بندی** | تیشرت، شلوار، جکت، کفش و کمیاب‌ترین‌ها |
| 🔍 **جستجوی زنده** | جستجوی لحظه‌ای در محصولات |
| 📦 **جزئیات محصول** | گالری تصاویر، انتخاب رنگ و سایز |
| 🛒 **سبد خرید** | با محدودیت موجودی و ذخیره در LocalStorage |
| ❤️ **علاقه‌مندی‌ها** | لیست محصولات موردعلاقه |
| 🔐 **احراز هویت** | ورود و ثبت‌نام با ایمیل |

### 👨‍💼 پنل مدیریت

| ویژگی | توضیح |
|-------|-------|

| 📦 **مدیریت محصولات** | افزودن، ویرایش و حذف محصولات |
